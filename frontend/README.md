# Frontend

本目录用于存放 FreeDinnerAgent 的 React 前端项目。

计划技术栈：

- React
- TypeScript
- Vite
- CSS Modules 或 Tailwind CSS

主要页面规划：

- 对话页面：展示多轮聊天、工具调用结果和记忆引用
- 记忆管理页面：查看、编辑、删除个人记忆
- 任务页面：展示由助理识别或创建的待办事项
- 设置页面：配置模型、隐私策略和工具开关

后续初始化命令建议：

```bash
npm create vite@latest . -- --template react-ts
npm install
npm run dev
```
